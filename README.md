📊 Marketing Funnel & Conversion Performance Analysis Using Tableau

📌 Project Overview

This project analyzes marketing campaign performance and customer conversion behavior using the Bank Marketing Dataset. The goal is to identify key factors influencing customer subscriptions and evaluate the effectiveness of marketing campaigns through interactive Tableau dashboards.

🎯 Objectives

* Analyze customer conversion patterns.
* Measure campaign effectiveness.
* Evaluate marketing channels and customer segments.
* Identify high-performing months, professions, and education groups.
* Generate actionable business insights through data visualization.

🗂️ Dataset

**Source:** Bank Marketing Dataset

The dataset contains customer demographic information, campaign details, contact methods, and subscription outcomes.

### Key Features

* Age
* Job
* Marital Status
* Education
* Balance
* Housing Loan
* Personal Loan
* Contact Type
* Month
* Campaign
* Subscription Outcome (Y)

🛠️ Tools & Technologies

* Tableau
* Data Visualization
* Business Intelligence
* Dashboard Design
* Data Analysis

📈 Dashboard Components

📍 KPI Cards

* Total Visitors
* Converted Customers
* Conversion Rate

📊 Visualizations

1. Customers vs Non-Customers Analysis
2. Contact Channel Analysis
3. Monthly Conversion Analysis
4. Job-wise Conversion Analysis
5. Education-wise Conversion Analysis

⚙️ Methodology

1. Imported and explored the Bank Marketing Dataset.
2. Created calculated fields for:

   * Visitors
   * Customers
   * Conversion Rate
3. Developed interactive visualizations.
4. Built a comprehensive Tableau dashboard.
5. Analyzed customer behavior and campaign performance.

🔍 Key Insights

* Identified the most effective contact channels for customer conversions.
* Determined the months with the highest conversion rates.
* Analyzed customer conversion behavior across job categories.
* Evaluated education-level impact on subscription outcomes.
* Generated insights to improve future marketing strategies.

💡 Business Value

This dashboard helps organizations:

* Improve marketing campaign performance.
* Increase customer conversion rates.
* Optimize resource allocation.
* Support data-driven decision-making.
